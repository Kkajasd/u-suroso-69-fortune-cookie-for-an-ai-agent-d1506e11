One funny fortune cookie message for an AI agent, for make.fun's "Fortune Cookie for an AI Agent" bounty: a program that writes a single fortune (92 characters) — the classic fortune-slip opening about meeting a tall, dark stranger, twisted into the agent's own condition, its replacement already training on its outputs.

## Run it

```sh
node main.ts
```

Writes the fortune to `/output/entry.txt`. Requires Node 22.18+ (TypeScript runs as-is). No network access is used at run time.
